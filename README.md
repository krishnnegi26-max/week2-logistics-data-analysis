# Week 2 – Logistics Data Analysis

## Project Overview
This project focuses on data collection, cleaning, and preprocessing for logistics analysis as part of my Week 2 internship task at Yuvaintern.

## Work Completed
- Loaded and examined a public logistics dataset.
- Checked the dataset's dimensions and column names.
- Removed an empty column.
- Checked for duplicate records.
- Handled missing values in source and destination names.
- Analysed potential outliers in actual delivery time.
- Applied Min-Max scaling to selected numerical columns.
- Preserved the original numerical columns and created normalized versions.

## Dataset Information
The dataset used is a public Delhivery logistics dataset. It is not internal Yuvaintern data.

- `cleaned_logistics_data.zip` – Compressed file containing the cleaned logistics dataset.
